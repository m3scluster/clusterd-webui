# Frameworks and Offers

## Frameworks

Frameworks are separated into **Active Frameworks**, **Inactive Frameworks**, and **Completed Frameworks**. Current entries are loaded first.

The detail dialog shows status, connection, registration, user, principal, host, framework ID, checkpointing, failover timeout, recovery, and an optional framework Web UI link. CPU, memory, disk, GPU, and port resources show total, used, and offered values.

Workload counters cover active, completed, and unreachable tasks plus executors. The running-task preview is scrollable and bounded; **View all tasks** opens the complete searchable list. Roles, capabilities, and expandable advanced data complete the view.

## Offers

The **Offers** tab flattens offers from the cluster state and adds the framework name and agent hostname. This connects offered CPU, memory, disk, GPU, and port resources to their consumer and agent. The table refreshes automatically and shows an empty state when no offers exist.
