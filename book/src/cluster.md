# Agents and Managers

## Agents

The agent table lists registered agents, status, and resources. An agent dialog shows identity, host and port, PID, version, registration timestamps, live utilization, and total/used/offered/available resources.

Active tasks on the agent are shown below. Completed and failed tasks are excluded from this default view. Attributes and capabilities are displayed separately. **View agent log** opens a bounded agent log tail.

## Manager details

The manager view shows server, leader/follower status, ClusterD version, and cluster name. Click a manager server to open its individual details and live utilization. **View Manager log** opens the manager log.

Interpret leader and manager metrics separately: the overview aggregates agent utilization, while manager details describe the selected manager.
